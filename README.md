# 두루마리 (Durumari)

마음을 두루마리에 말아 전하는 온라인 롤링페이퍼 서비스.

## 컨셉

- 큰 흰 전지 한 장에 친구들이 형식 없이 자유롭게 글을 적는 방식
- 완성된 롤링페이퍼도 전지에 무작위로 배치해 현실감 있게 표시

## 핵심 기능 (프로토타입)

- 원링크(숏링크) 초대 — 가입 없이 바로 작성하는 게스트 모드
- 맞롤링페이퍼 — 써준 뒤 상대에게도 작성을 요청
- 타임캡슐 — 1년 뒤 이메일로 다시 열어보기
- 사람 1명 아래 여러 소속(학교·회사·동호회) 구조, 모임별 탭 필터
- 이모지·스티커 꾸미기, 드래그 이동

## 실행

`index.html`을 브라우저에서 열면 됩니다. (정적 프로토타입 — 실제 메일 발송·링크 라우팅·결제는 미구현)
